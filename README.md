# Lucas & Sophia — GitHub Pages

This repository is a GitHub Pages copy reconstructed directly from the Save Page WE capture supplied for the Dreams Invite page.

The captured HTML already contains the rendered page, embedded images, embedded font data, CSS, SVGs, and the canvas snapshot. The page therefore does not depend on the original Dreams Invite server for its visual assets.

## Deploy

1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.
